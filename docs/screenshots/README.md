# Screenshot archive

The user interface across versions, kept for before/after comparisons.

| Folder | Version | What |
|---|---|---|
| `1.1.15/` | 1.1.15 (PS5 FFPFSC ULTRA) | The README screenshots of that release: main window, Pack, Convert, Patch, fPKG, Browse, Settings |
| `1.1.19/` | 1.1.19 (PS5 FFPFSC ULTRA) | Last UI before the 1.2.0 redesign: main window dark and light with three sample jobs, the Add job dialog, Settings |
| `1.2.0/` | 1.2.0 (PS5 UltraPack) | The redesign with the same three sample jobs: main window dark and light, Add job (also with .pkg output), Settings pages (also light), Look inside, the compression and first-run panels, and the error (also light) and job result windows (short and long report) |

The 1.1.19 and 1.2.0 sets were taken from the source (1.1.19 at commit `d5a04ea`) with an isolated profile and neutral
sample games ("Example Quest", "Sample Racer", "Demo Adventure", placeholder title IDs) on a scratch
volume named "UltraPack Demo".
